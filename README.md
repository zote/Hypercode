# Hypercode
A new developer best friend inspired by supacode

Pendências e ideias são controladas nas [issues](https://github.com/zote/Hypercode/issues).

## Hypercode

App de macOS que lista os worktrees de um repositório e abre o `claude` em cada um. Para baixar,
instalar, compilar e publicar uma versão nova, veja [hypercode/README.md](hypercode/README.md):

- [Baixar e instalar](hypercode/README.md#baixar-e-instalar) — zips em [Releases](https://github.com/zote/Hypercode/releases)
- [Testes e CI](hypercode/README.md#testes-e-ci)
- [Publicar uma versão](hypercode/README.md#publicar-uma-versão)
